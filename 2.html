Uma regra CSS é o conjunto de instruções que define como um elemento HTML deve aparecer na tela. Ela é formada por três partes: Seletor → indica qual elemento será estilizado Propriedade → o que será alterado (cor, tamanho, etc.) Valor → como será alterado Exemplo CSS Completo
